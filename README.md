
# 최수연 | 금융 데이터 분석 · AI 서비스 기획

금융 데이터를 수집·정제하고 통계적으로 검토하며,
분석 결과를 사용자가 이해할 수 있는 정보와 화면으로 연결합니다.

이 저장소는 팀 프로젝트에서 제가 담당한 작업을 정리하는
개인 포트폴리오입니다. 코드와 결과 자료를 순차적으로 추가하고 있습니다.

## 1. 주식 이상징후 탐지 및 관련 뉴스 조회 서비스

주가·거래량에서 이상징후를 탐지하고,
해당 날짜에 보도된 뉴스를 연결해 당시 상황을 함께 살펴보는 팀 프로젝트입니다.

### 담당 작업
- 이상징후 탐지 모델 설계 초안 작성
- Rolling OLS 기반 분석 구조와 잔차·거래량 활용 방식 구상
- Streamlit 기반 프론트엔드 구현
- 탐지 결과와 해당 날짜의 뉴스를 확인하는 화면 구성

탐지 결과는 통계적 이상 후보이며,
연결된 뉴스가 이상징후의 원인임을 입증하는 것은 아닙니다.

[프로젝트 상세 보기](projects/stock-fds/README.md)

## 2. 금융 뉴스 기반 맞춤형 브리핑

미국 뉴스와 시장지표를 국내 보유종목과 연결해
투자자가 필요한 정보를 확인할 수 있도록 기획한 팀 프로젝트입니다.

### 담당 작업
- 금융·시장지표 수집·정제 및 데이터 품질 검토
- WI26 26개 업종과 시장지표의 통계적 관계 분석
- 뉴스·공시의 출처 및 기업 관계 데이터 구조화
- Neo4j 기반 관계 조회 파일럿 구성
- 서비스 전체 화면 기획·구성 및 Figma 프로토타입 제작

### 화면 기획
홈, 뉴스 브리핑, 밤사이, 내 종목, 브리핑 보관을 중심으로
정보 배치와 화면별 이용 흐름을 구성했습니다.

[Figma 화면 기획·프로토타입 보기 · 작업 중](https://www.figma.com/design/L0rZsiiTEqGkKs4Z0OV4WP?node-id=0-1)

Python, pandas, NumPy, statsmodels, Matplotlib,
Streamlit, Neo4j, Cypher, Figma, Git·GitHub

## 작업 범위

- 팀 공동 작업과 개인 담당 범위를 구분해 기록합니다.
- 코드 작성·수정·검토 과정에서 AI 도구를 활용했습니다.
- 분석 결과에는 데이터 범위, 검증 조건과 한계를 함께 설명합니다.
