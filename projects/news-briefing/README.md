# 금융 뉴스 기반 맞춤형 브리핑

미국 뉴스와 시장지표를 국내 보유종목과 연결해,
투자자가 필요한 정보를 확인할 수 있도록 기획한 팀 프로젝트입니다.

## 개인 담당 범위

### 금융 데이터 분석
- 금융·시장지표 수집·정제 및 결측치와 날짜 정렬 검토
- WI26 26개 업종과 시장지표의 통계적 관계 분석
- 시장 요인을 고려한 분석 조건 비교와 결과 시각화
- 분석 결과의 활용 가능성과 한계 검토

### 뉴스·기업 관계 데이터
- 뉴스·공시의 출처 및 기업 관계 데이터 구조화
- Neo4j와 Cypher를 활용한 관계 조회 파일럿 구성
- 관계의 근거와 출처를 확인할 수 있는 데이터 구조 검토

### 서비스 화면 기획
- 서비스 전체 화면의 정보 배치와 사용자 흐름 구성
- 홈, 뉴스 브리핑, 밤사이, 내 종목, 브리핑 보관 화면 구성
- Figma를 활용한 화면 설계 및 프로토타입 제작

[Figma 화면 기획·프로토타입 보기](https://www.figma.com/design/L0rZsiiTEqGkKs4Z0OV4WP?node-id=0-1)


## 결과물의 범위

- 통계 분석은 지표와 업종의 관계를 탐색한 작업이며,
  미래 수익률 예측 성능을 입증한 결과는 아닙니다.
- Neo4j 작업은 관계 구조와 조회 가능성을 검토한 파일럿입니다.
- Figma는 개발 중인 서비스의 UI 프로토타입이며,
  화면의 수치와 콘텐츠에는 시연용 예시가 포함되어 있습니다.

## 사용 기술·도구

Python, pandas, NumPy, statsmodels, Matplotlib,
Streamlit, Neo4j, Cypher, Figma
