# WI26 업종과 국내 금융지표의 관계 분석

금융 뉴스 브리핑 서비스에서 시장지표와 업종을 연결할 근거를 검토한 탐색적 분석입니다. 팀 프로젝트 중 개인 담당 분석의 대표 자료를 선별했습니다. 코드 작성·수정·검토 과정에서 AI 도구를 활용했습니다.

## 분석 조건과 결과

- 수익률 분석 기간: 2023-11-07 ~ 2026-11-05
- WI26 26개 업종 × 국내 금융지표 6개 = 156개 조합, 업종별 729개 관측치
- 기본모형: 업종 수익률 ~ 상수 + KOSPI 수익률
- 확장모형: 기본모형 + 금융지표 하나
- OLS, HAC 시차 5 (Bartlett, 소표본 보정), 전체 156개 지표 계수에 BY 보정
- 보정 전 5% 기준 3개, BY 보정 후 5% 기준 0개

BY 보정 p값은 156개 모두 1.0입니다. 저장된 보정 전 p값으로 BY를 재계산해 일치함을 확인했습니다. 최소 보정 전 p값은 0.014724이며, 이 검정군에 BY의 순위 조정·단조화·상한 1 처리를 적용한 결과입니다.

모든 귀무가설이 참이고 각 검정의 유의수준이 정확히 5%라면, 보정 전 기각 수의 기대값은 156 × 0.05 = 7.8개입니다. 이는 독립성을 요구하지 않는 기대값 설명이며, 반드시 약 8개가 나와야 한다는 뜻도, 실제 기각 3개가 거짓 양성이라는 판정도 아닙니다. 기각 수만으로 관계의 존재·부재를 결론 내리지 않습니다.

### 보정 전 p값 기준 상위 5개

| 업종 | 지표 | 계수 | HAC p값 | BY 보정 p값 | 조정 R² 증가 |
|---|---|---:|---:|---:|---:|
| 상사,자본재 | 장단기 금리차 | 0.0764 | 0.0147 | 1.0000 | 0.0028 |

| 상사,자본재 | 국고채 10년 | 0.0312 | 0.0485 | 1.0000 | 0.0024 |

| 에너지 | 국고채 3년 | 0.0379 | 0.0641 | 1.0000 | 0.0030 |

표는 표시용으로 반올림했습니다. 전체 정밀도는 [원본 결과표](results/regression_comparison.csv)에 보존했습니다. 위 순위는 지표 채택 순위가 아닙니다. [표본 검사 결과](results/sample_audit.csv)도 함께 제공합니다.

## 코드와 입력 CSV

[분석 노트북](notebooks/wi26_domestic_analysis.ipynb)

| 칼럼 | 의미 | 형식·단위 |
|---|---|---|
| date | 수익률 종료일 | YYYY-MM-DD |
| previous_sector_date | 수익률 시작일 | YYYY-MM-DD, date보다 이전 |
| sector_code | WI26 업종 코드 | 문자열 |
| sector_name | 업종명 | 문자열 |
| sector_return_pct | 업종 수익률 | %, 1은 1% |
| kospi_return_pct | KOSPI 수익률 | %, 1은 1% |
| KR3Y_change | 국고채 3년 금리 변화 | bp |
| KR10Y_change | 국고채 10년 금리 변화 | bp |
| KR_CORP_AA3Y_change | 회사채 AA- 3년 금리 변화 | bp |
| KR_CREDIT_change | 신용스프레드 변화 (회사채 AA- 3년 − 국고채 3년) | bp |
| KR_CURVE_change | 장단기 금리차 변화 (국고채 10년 − 국고채 3년) | bp |
| USDKRW_change | 달러/원 환율 변화율 | %, 1은 1% |


한 행은 업종·날짜 한 쌍입니다. 업종·날짜 중복과 결측치는 허용하지 않으며, 모든 업종은 같은 729개 날짜를 사용합니다. 같은 날짜의 시장·금융지표 값과 수익률 시작일은 업종 간 동일해야 합니다. 금리 변화 1bp는 0.01%p입니다.

`data/sample_input.csv`는 칼럼 형식을 보여주는 **가상 자료**입니다. 실제 시세나 분석 결과가 아니며, 26개 업종·729일 검사 조건을 충족하지 않아 전체 회귀 실행에는 사용할 수 없습니다. 샘플을 실제 입력 파일명으로 바꾸거나 검사를 완화해 기존 결과를 재현한 것으로 해석하지 마세요.

## 실행

기존 결과 기록 및 이번 검증 환경: **Python 3.11.16**. 패키지 버전은 `requirements_analysis.txt`에 고정했습니다.

```bash
python -m pip install -r requirements_analysis.txt
```

1. 동일한 원자료 `regression_inputs_domestic.csv`를 `data/`에 준비합니다. 원자료는 배포본에 포함하지 않았습니다.
2. Jupyter 또는 VS Code의 Python 3.11 커널에서 노트북을 엽니다. Jupyter 사용 시 해당 환경에 `ipykernel` 등 실행 도구가 별도로 필요합니다.
3. 작업 디렉터리를 이 `market-analysis` 폴더 또는 그 안의 `notebooks`로 두고 셀을 순서대로 실행합니다.
4. 검증과 분석 완료 후 `results/<실행 ID>/`에 결과·입력 SHA256·실행 기록·패키지 버전을 저장합니다. 기존 배포 결과는 덮어쓰지 않습니다.

## 한계와 다음 단계

과거 동시점의 관계를 검토한 분석이며 미래 수익률 예측이나 인과관계를 입증하지 않습니다. 해당 표본과 모형에서 보정 후 유의한 관계를 확인하지 못했으며, 관계가 전혀 없다는 증명은 아닙니다. 발표 시점 및 당시 이용 가능 데이터의 검증과 표본 외 평가를 수행한 결과가 아닙니다. HAC 시차 1·10 및 표본 변화에 대한 민감도는 후속 검토 항목입니다. 이 초기 국내지표 실험을 미국지표·첫반응 실험 결과와 혼합해 해석하지 않습니다.
