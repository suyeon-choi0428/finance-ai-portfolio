# 주식 이상징후 탐지 및 관련 뉴스 조회 서비스

주가·거래량에서 이상징후를 탐지하고,
이상징후가 나타난 날짜에 보도된 뉴스를 연결해
사용자가 당시 상황을 함께 살펴볼 수 있도록 만든 팀 프로젝트입니다.

## 개인 담당 작업

### 이상징후 탐지 모델 설계 초안
- 시장·산업 요인을 고려한 Rolling OLS 기반 분석 구조 설계
- 회귀 잔차와 거래량 지표를 활용한 이상 후보 선별 방식 구상
- 팀의 모델 논의를 위한 초기 분석 방향과 기준 정리

### Streamlit 프론트엔드 구현
- Streamlit을 활용한 서비스 사용자 화면 구현
- 이상징후 탐지 결과와 해당 날짜의 뉴스를 확인하는 화면 구성
- 분석 결과를 사용자가 탐색할 수 있도록 정보 배치와 이용 흐름 구성

## 서비스 흐름

1. 주가·거래량 데이터를 바탕으로 이상징후를 탐지합니다.
2. 이상징후가 나타난 종목과 날짜를 확인합니다.
3. 해당 날짜에 보도된 뉴스를 연결해 당시 상황을 살펴봅니다.

## 결과 해석 시 유의점

- 탐지 결과는 통계적 이상 후보이며,
  실제 불공정거래를 확정하는 판정은 아닙니다.
- 연결된 뉴스는 당시 상황을 살펴보기 위한 참고 자료이며,
  이상징후의 원인임을 입증하지는 않습니다.

## 사용 기술·도구

Python, Streamlit

## 프로젝트 및 기여 안내

팀 프로젝트 중 개인 담당 작업을 정리한 페이지입니다.
탐지 모델 설계 초안과 Streamlit 프론트엔드 구현을 담당했습니다.
코드 작성·수정·검토 과정에서 AI 도구를 활용했습니다.
대표 코드와 화면 자료를 순차적으로 추가할 예정입니다.
