# 주식 이상징후 탐지 서비스 — Streamlit 화면 코드

[Streamlit 앱 코드 보기](app.py)

미니 프로젝트 시연 ZIP에서 선별한 사용자 화면 코드입니다. 주식 이상징후 탐지 결과와 해당 종목·날짜에 연결된 뉴스·공시 설명 및 출처를 함께 탐색합니다.

## 개인 담당 범위

이상징후 탐지 모델의 설계 초안과 Streamlit 프론트엔드 작업을 담당했습니다. 코드 작성·수정·검토에는 AI 도구를 활용했습니다. 이 폴더는 화면 구현 결과를 보여주며 모델 설계 초안 노트북은 포함하지 않습니다. 팀 전체 결과를 개인 단독 구현으로 주장하지 않습니다.

## 코드에 포함된 화면·기능

- 관심 종목 선택과 로컬 SQLite 기반 설정 저장
- 거래일 달력·종목 검색·경보 목록과 상세 화면 이동
- 주가·거래량 경보와 잔차·Z점수·모형 기여도 표시
- 종가·거래량·모형 예상 대비 이탈 추이 차트
- 저장된 뉴스 설명·공시 근거 및 원문 링크 조회
- 비교군 구성과 모형 해석 안내
- CSV 업로드 및 필수 칼럼·날짜·중복·경보 형식 검사

## 실행

앱 헤더에 기록된 Streamlit 버전을 사용했습니다. pandas와 Altair는 버전 범위를 지정했으며 별도의 전체 실행 환경 고정본은 아닙니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

실행에는 원본 분석 결과 `stored_data/daily_results.csv`가 필요합니다. 해당 파일이 없으면 화면의 업로드 기능을 사용합니다. 입력 자료는 이 공개 폴더에 포함하지 않았습니다. 이 폴더만으로 완성된 시연 데이터까지 재현되는 것은 아닙니다.

필수 칼럼은 `date`, `code`, `name`, `market`, `stock_return`, `expected_return`, `price_residual`, `price_alert`, `volume_alert`, `alpha`, `market_part`, `sector_part`입니다. 날짜는 날짜로 변환 가능한 값, 종목코드는 6자리 문자열, 경보는 True/False 또는 1/0이며 날짜·종목 조합은 중복될 수 없습니다. 추가 칼럼과 표시 기준은 `validate_results()` 및 화면 코드를 참고하세요.

뉴스·공시 설명은 `result/기업명_YYYYMMDD/user_explanation.txt`, 출처는 같은 폴더의 `evidence.json`, 관련 뉴스는 `source_data/source_news/.../source_news.json` 등의 기존 파일을 읽습니다. 연결 자료가 없으면 준비 중으로 표시합니다. 상세 규칙은 앱 파일 맨 위의 설명에 있습니다.

## 구현 범위와 공개 자료

앱은 저장된 `price_alert`·`volume_alert` 값을 표시하며 회귀모형을 다시 학습하거나 탐지 결과를 새로 계산하지 않습니다. `expected_return`은 해당 분석모형의 설명값이며 미래 수익률 예측 성능이 아닙니다. 뉴스 연결 또한 저장 파일 조회로 동작하며 이 앱에서 추가 뉴스 API를 호출하지 않습니다. 실제 푸시 알림 발송 기능은 없습니다.

원본 `app.py`의 내장 압축 종가·거래량 데이터는 코드와 함께 유지했습니다. 원본 분석 결과 CSV, 실제 기사 전문·공시 자료, 생성된 설명문·원시 출력, 개인 관심 종목 SQLite DB는 배포하지 않았습니다. 앱의 조회 기간 설정은 2025-01-01 ~ 2026-06-30이며, 원본 결과 자료에 존재하는 전체 기간과 다를 수 있습니다.

통계적 이상 후보는 불공정거래 확정 판정이 아니며, 연결 뉴스가 움직임의 원인임을 입증하지 않습니다. 본 앱은 단일 사용자 로컬 시연용이며 사용자 인증·다중 사용자 운영을 검증한 서비스가 아닙니다.

## 이번 선별 과정의 확인

ZIP에서 앱의 함수·입출력 구조를 확인하고 Python 구문 검사를 수행했습니다. 이번 정리에서 브라우저 화면이나 모든 상호작용의 정상 동작을 재검증한 것은 아닙니다. 공개한 앱 코드의 바이트는 제공된 ZIP 원본과 동일합니다. 원본 ZIP은 수정하지 않았습니다.
